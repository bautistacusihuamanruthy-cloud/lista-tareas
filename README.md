 Descripción del Proyecto
Este es un proyecto colaborativo diseñado para gestionar y realizar el seguimiento de tareas pendientes. Permite organizar las actividades del equipo de forma clara y eficiente utilizando metodologías ágiles de desarrollo.

 Funcionalidades Principales
Registrar tareas:** Añadir nuevas actividades pendientes a la lista de manera rápida.
Mostrar tareas:** Visualizar de forma clara y ordenada el listado completo de los pendientes.
Marcar tareas como completadas:** Cambiar el estado de las tareas finalizadas para llevar un control del progreso.

 Tecnologías Utilizadas
Git & GitHub:** Para el control de versiones y el trabajo colaborativo en equipo.
Markdown:** Para la documentación clara y estructurada del repositorio.
